# LunaScan MVP

A polished virtual MVP for an ECE 6001 NASA Technology Transfer project.

## Run it

### Windows
1. Make sure Python is installed.
2. Double-click `run_windows.bat`.

Or open PowerShell in this folder and run:

```powershell
python server.py
```

Then visit:

```text
http://localhost:8080
```

### macOS / Linux

```bash
python3 server.py
```

Then visit:

```text
http://localhost:8080
```

The server automatically tries to open your browser.

## Project concept

**NASA Shortfall 5.1:** Locate, characterize, and map useful resources on the lunar surface.

**Thesis:** Lunar explorers will buy LunaScan because it enables rapid and efficient classification of lunar resources.

## MVP test

Ask the participant to use the site and then say:

> Imagine you are deciding where to send a rover to investigate lunar resources. Use LunaScan to choose your first target. Tell us what information influenced your decision and what information you wish you had.

All data shown in the MVP is simulated.
